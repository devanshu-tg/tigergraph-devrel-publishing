Hacker House Goa 2026 is an in-person hacker house in Goa from 28 to 31 October 2026. TigerGraph is a track partner, and six teams selected through the TigerGraph challenge will build on site.

## The selection task: Agentic Fraud Investigation

To earn a place, teams built an AI agent on TigerGraph that investigates card-fraud alerts the way an analyst would. Working on a bank dataset of about 590,000 transactions with no fraud labels, the agent had to:

- gather evidence from the graph (shared devices, connected cards, transaction history and past cases) using TigerGraph MCP and GraphRAG,
- judge how certain it is, and ask for more evidence when it isn't sure,
- recommend next-best actions under the bank's fraud policy, with the right approval route,
- write a suspicious activity report when one is required, and save the finished case back to the graph as memory.

Each team submitted answers for 20 benchmark cases, a public GitHub repository, a demo video and a technical blog post. **232 teams** submitted a solution.
