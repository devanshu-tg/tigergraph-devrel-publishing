RAG-Benchmark-lab - Benchmarking LLM-only, Basic RAG, and GraphRAG pipelines for AML investigation using TigerGraph, ChromaDB, and GPT-4o-mini on 2M embedded transaction chunks.

## Dataset

https://www.kaggle.com/datasets/ealtman2019/ibm-transactions-for-anti-money-laundering-aml

## Benchmark results

Token reduction: GraphRAG uses ~31% fewer input tokens than Basic RAG
Cost: GraphRAG ~53% cheaper per query
Latency: GraphRAG 5–8x faster end-to-end
Accuracy: GraphRAG 7.5–8.5 / 10 judge, 80–100% pass rate at ≥7, BERTScore F1 0.72–0.85
