This project is an AI-powered GraphRAG intelligence platform developed for the TigerGraph GraphRAG Hackathon. The system compares traditional LLM responses, Basic RAG pipelines, and GraphRAG-based retrieval to analyze differences in reasoning quality, factual accuracy, token efficiency, and retrieval performance.

The platform combines vector search, knowledge graphs, and graph-based reasoning to improve contextual understanding and multi-hop retrieval. It includes an interactive analytics dashboard that visualizes token usage, latency, retrieval quality, and graph traversal paths in real time.

Built using technologies such as LangChain, FastAPI, ChromaDB, and modern frontend frameworks, the project aims to demonstrate how GraphRAG can enhance AI systems beyond standard semantic retrieval by leveraging structured relationships between entities and documents.
