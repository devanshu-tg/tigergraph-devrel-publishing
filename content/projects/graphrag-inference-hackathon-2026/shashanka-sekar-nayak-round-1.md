An AI-powered benchmarking platform designed to compare and analyze multiple Retrieval-Augmented Generation (RAG) architectures for entertainment and movie intelligence applications.

The system integrates Basic Vector RAG, Hybrid RAG, and GraphRAG pipelines into a unified interactive dashboard, enabling real-time comparison of retrieval quality, contextual understanding, latency, and response generation performance.

Built using Python, Streamlit, ChromaDB, Gemini API, and graph-based retrieval techniques, the platform supports semantic search, keyword retrieval, graph-enhanced reasoning, benchmarking analytics, and interactive visualizations.

Core Features
Multi-pipeline AI retrieval comparison
GraphRAG-based contextual reasoning
ChromaDB vector storage integration
Semantic + keyword hybrid retrieval
Real-time benchmark analytics
Interactive graph visualization
Parallel query execution
Configurable persistent and memory modes
LLM-generated intelligent responses
Tech Stack

Python • Streamlit • ChromaDB • Gemini API • Plotly • Vector Embeddings • Knowledge Graphs • RAG Pipelines

Objective

To evaluate how graph-enhanced retrieval systems improve contextual understanding and answer quality compared to traditional vector-based retrieval methods in entertainment intelligence systems.

## Dataset

Dataset Domain & Source  Domain: Entertainment Intelligence / Movie Recommendation & Analysis  Dataset Source: IMDb Movies Dataset (IMDb Top Movies Dataset) from Kaggle.The project uses a movie-based dataset containing information such as:  Movie titles Genres Cast and directors Ratings Release years Plot summaries Metadata for semantic retrieval and graph relationships  The dataset is processed and converted into vector embeddings for semantic search and graph-based retrieval experiments using ChromaDB and GraphRAG pipelines.
