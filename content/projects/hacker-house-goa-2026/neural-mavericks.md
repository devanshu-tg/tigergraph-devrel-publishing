## Notes from the team

This is a hackathon prototype, not a production fraud system. Customer replies, actions, approvals, and SARs are simulated; no real card, customer, or regulator is contacted. The public repo contains all 20 case files and the submitted run uses deterministic.

## Details

- **LLM:** Anthropic Claude Opus 5
- **Agent framework:** Custom Python state-machine/orchestrator with the official TigerGraph MCP gateway and pyTigerGraph; Streamlit analyst UI.
- **TigerGraph deployment:** Savanna
