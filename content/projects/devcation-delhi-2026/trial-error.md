## How the team used TigerGraph

TigerGraph is used as the core graph database to model the network as nodes (devices, vulnerabilities, attackers) and edges (connections, exploits). Custom GSQL queries are used to detect attack paths and calculate risk. These queries are accessed via REST APIs from the FastAPI backend, which processes the results and sends them to the frontend for visualization and analysis.
