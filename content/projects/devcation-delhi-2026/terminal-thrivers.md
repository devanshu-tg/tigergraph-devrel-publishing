## How the team used TigerGraph

We integrated TigerGraph Cloud as the core graph engine for NexusGuard to model complex, multi-hop financial transactions. Using the pyTigerGraph library in our FastAPI backend, we mapped user accounts as vertices and wire transfers as edges. This graph topology allows us to instantly query network features and feed them into our machine learning and Gemini LLM pipeline to detect layered money-laundering patterns in real time.
